issue, not a healthy steady state. Likewise, a completed CarePlan with zero
decision models does not prove the DMN path.

The earlier failed ingester run returned 403
`credential_endpoint_mismatch` because the profile still authorized
`api.openai.com` while the CR called Enmaas. Updating the profile endpoint
without changing the Secret fixed that specific failure; an authenticated,
read-only `/v1/models` request from the existing LLM sandbox returned 200,
and the subsequent ingester run completed.

## Resource ownership audit

The namespace's BFF/UI Deployments and Services, pipeline policies,
SandboxRequests, and SonataFlow CRs are operator-owned. SonataFlow creates its
own workload Deployments and Routes. MinIO and the HTTP service proxy are
bootstrap-managed; the gateway is Helm-managed. The
`openshell-sandbox-supervisors` and `openshell-sandbox-workloads`
NetworkPolicies carry `openshell.ai/managed-by=openshell` and were created by
OpenShell, so they are **not** extra manual bootstrap manifests to copy into
this repository. No other required, manually maintained in-cluster policy or
Service was found in this audit.
